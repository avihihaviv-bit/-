# מסלול (Maslul)

מערכת ניהול חיים אישית: שגרה יומית, משימות, הרגלים, מטרות, פוקוס, לוח שנה, נתונים ומאמן AI. PWA בעברית מלאה (RTL), עובד גם אופליין.

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה הראשית (שגרה, הרגלים, גיימיפיקציה, כושר, תזונה, Glow Up, כסף, למידה, הגדרות) |
| `core.js` | לוגיקה טהורה ונבדקת: Migration של נתונים, משימות, מחזוריות, סטטיסטיקות, תובנות |
| `extras.js` | בדיקת עדכונים, מה חדש, קיצורי מקלדת, ווידג׳טים נוספים לבית, תוספות לכושר/כסף/למידה |
| `features.js` / `features.css` | מודולים: משימות (רשימה/Kanban), לוח שנה, מחברת + Inbox, סקירות, נתונים, מאמן AI, פוקוס, דיבור ס/ש, חיפוש גלובלי, הוספה מהירה, התראות, גיבויים |
| `api/coach.js` | פונקציית Vercel למאמן ה-AI (המפתח נשמר רק בשרת) |
| `sw.js`, `manifest.json` | PWA: התקנה, אופליין, עדכוני גרסה |

## נתונים
- נשמרים ב-`localStorage` (`maslul_state_v1`) עם `schemaVersion` ו-Migration שרק מוסיף שדות ולא מוחק.
- גיבוי אוטומטי יומי ב-IndexedDB (14 אחרונים), גיבוי לפני כל שחזור/איפוס, ייצוא/ייבוא JSON בהגדרות.
- נתונים פגומים לא נמחקים: נשמר עותק גולמי ב-`maslul_recovery_<time>`.

## חיבור המאמן החכם (AI)
ב-Vercel: **Settings → Environment Variables** → `ANTHROPIC_API_KEY` = המפתח שלך, ואז Redeploy.
בלי מפתח, המסך מציג "לא מחובר" ותובנות מקומיות שמסומנות במפורש כ"לא AI".

## בדיקות
```bash
npm install
npm test
```

## שחרור גרסה חדשה
כדי שכפתור "בדוק עדכונים" יזהה גרסה חדשה: לעדכן את אותו מספר גרסה ב-`version.json` וב-`APP_VERSION` שבתוך `extras.js` (בדיקה ב-`npm test` מוודאת שהם זהים), ולהוסיף שורה ל-`CHANGELOG` שם.
